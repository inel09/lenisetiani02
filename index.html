Praktik Simpel Kelima Materi

Langkah dasar praktik yang bisa langsung dicoba di Lab TKJ.

1. Praktik MikroTik (Dasar)

Hubungkan ke PC lewat port 2 dengan kabel LAN. Buka aplikasi WinBox, login via MAC Address, lalu ubah nama identitas router melalui menu System > Identity.

2. Praktik Konfigurasi IP

Masuk ke Control Panel > Network Connections. Klik kanan Ethernet > Properties > IPv4. Masukkan IP 192.168.1.10 dan uji lewat CMD dengan mengetik ping 192.168.1.1.

3. Praktik Instalasi Windows & Linux

Gunakan Flashdisk Bootable installer. Atur urutan booting utama dari USB di menu BIOS/UEFI, lalu ikuti instruksi instalasi di layar hingga sistem operasi siap dipakai.

4. Praktik Kabel LAN (Crimping)

Susun kabel UTP standar Straight (Pin 1–8) ke konektor RJ-45, lalu jepit kuat menggunakan tang crimping dan uji dengan LAN Tester.

Konsep & Analogi

Pengertian Materi TKJ

1. Tentang MikroTik

Perangkat keras dan sistem operasi router yang berfungsi mengatur lalu lintas internet, membagi kecepatan bandwidth, serta mengamankan koneksi jaringan sekolah.

2. Konfigurasi IP

Alamat identitas unik berupa deretan angka (seperti alamat rumah) agar komputer satu dan lainnya dapat saling mengenali dan mengirim data di dalam jaringan.

3. Instalasi Windows & Linux

Proses memasang sistem operasi utama (jiwa komputer). Windows ramah untuk penggunaan harian, sedangkan Linux sangat tangguh untuk kebutuhan server jaringan.

4. Kabel LAN

Jalur fisik berupa kabel UTP yang menghubungkan komputer langsung ke switch atau router agar koneksi data berjalan cepat dan stabil tanpa gangguan sinyal.

5. Website

Kumpulan halaman informasi digital yang dibangun menggunakan kode HTML dan CSS sehingga dapat diakses siapa saja melalui browser internet.
